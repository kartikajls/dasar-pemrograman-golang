<h1>Tour-Guide Booking System</h1>

<p>Tour-Guide Booking System adalah program sederhana berbasis terminal yang dibuat menggunakan Golang.
Program ini digunakan untuk melakukan pemesanan jasa tour guide berdasarkan jenis layanan dan jumlah jam yang dipilih.
Project ini dibuat sebagai latihan untuk memahami dasar-dasar pemrograman menggunakan Go.</p>

<h2>Tujuan Project</h2>
<p>Project ini dibuat untuk latihan memahami dasar-dasar Golang, terutama penggunaan struct, map, slice, looping, conditional, input user, konversi tipe data, dan error handling.</p>

<h2>Fitur</h2>
<p>📌 Menampilkan daftar layanan tour guide.</p>
<p>📌 Memilih jenis tour guide.</p>
<p>📌 Memilih jumlah jam.</p>
<p>📌 Menghitung subtotal pesanan.</p>
<p>📌 Memesan lebih dari satu layanan.</p>
<p>📌 Menampilkan ringkasan pesanan.</p>
<p>📌 Menghitung total pembayaran.</p>
<p>📌 Validasi input dari pengguna.</p>
